這是開發紀錄的第一篇。之後可以在這裡寫：

- 做專案時卡過的技術問題，怎麼解掉的
- 一段時間的進度整理（類似 devlog）
- 對某個工具 / 框架的心得

要新增文章時，在 `content/posts/` 底下新增一個 `.md` 檔即可，檔名會變成網址的 slug。開頭的 frontmatter（`title` / `date` / `excerpt` / `tags`）決定列表頁顯示的資訊，下面的內容用一般 Markdown 寫。

```ts
// 也支援程式碼區塊
function hello() {
  console.log("hello devlog");
}
```
